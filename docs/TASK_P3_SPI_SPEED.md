# 任务书 P3：SD SPI 速率悬崖探测（初赛后执行）

> 状态：**已归档，初赛（11.4）后启动**。前置依赖：无（D3+板测视频完成后再做）。
> 背景：2026-11-01 速率阶梯实验的完整结论。

## 1. 已测定事实

| 配置 | 目标 SCK | 实际 SCK | 板测 | 依据 |
|---|---|---|---|---|
| 冻结 g32 | 6.25MHz | 6.25MHz | ✅ 长期稳定 | WC=25C |
| P1 | 12.5MHz | 12.5MHz | ✅ | WC=25C，OFF 累计 2.76MB |
| P2 | 16.67MHz | **25MHz（无效实验）** | ❌ | 参数 16_666_667 被 `clock_freq/(2*f)` 整数截断为 DIV=1 |
| P0 | 25MHz | 25MHz | ❌×2 | OFF=0、RSP 全 FF、重试后卡死 |

- 分频架构：`clk_div_var` 每 `div_value` 个整数周期出一个节拍，SCK 每节拍翻转
  → **SCK = 50MHz/(2×DIV)，DIV∈整数 → 可产生速率仅 25/N 系列（25、12.5、8.33…）**
- **12.5~25MHz 之间在当前 RTL 下不可达**；本任务的悬崖位置 ∈ (12.5, 25]，待实验
- 25MHz 失败签名 = 死寂（0 字节、命令无响应），非 CRC 错乱 → 疑为 MOSI 命令流在卡端采样失败（信号完整性或卡时钟容差），中间速率存在通过的可能性但期望偏低

## 2. 方案：分数节拍分频（首选，改动最小）

节拍间隔在 floor 与 ceil 之间交替（如 +2,+1,+2,+1…），SCK 周期均摊到非整数周期：

- **P3-16.67**：+2/+1 交替 → 周期均摊 3 周期 → 16.67MHz，占空比 33/67 交替
  - 卡端 MOSI 建立时间 = 高电平最短段 = 1 周期 = 20ns ≫ 规格要求，安全
  - 主机采样 MISO 在 SCK 上升沿后的 posedge，建立时间 2 周期 = 40ns，安全
- **P3-19.2**：+3/+1 交替（周期均摊 2.6）→ 19.2MHz（备选进阶）
- 数据通路保持 50MHz 单时钟域，**无 CDC 改动**；仅 `clk_div_var` 增加分数模式参数
  （或旁路出 `clk_div_frac` 新模块，实例化时按参数选择）

### 验收判据（铁律：判据先行）

1. `tb_clk_div_frac`：分数模式波形判据 —— 节拍间隔序列、SCK 周期均摊值、占空比极值
2. 复用 `tb_sd_drain` 全套（drain/bmp/wav/cart 四用例）在分数节拍下回归
3. 板测：WC=25C + 音乐 48kHz 无 popping（RATECHK 比例判据）+ 连续播放 10 分钟无 B14 看门狗误报
4. 若 16.67 过：再探 19.2；若不过：**12.5MHz 为最终极限，速率阶梯关闭**，结果写入本文档

## 3. 备选方案（分数节拍失败时）

- SD 引擎独立 PLL 域（30MHz → DIV=1 → 15MHz）：CDC 改动大，需全握手同步器评审
- CMD6 高速模式（50MHz）：板级 SI 在 25MHz 已死，期望最低，不推荐

## 4. 价值

- 过 16.67：视频帧预算 45→60KB（+33%），或 24fps 下提升质量档
- 不过：速率阶梯测到分毫不剩，"每一段中间速率都有板测数据"本身即答辩级叙事
