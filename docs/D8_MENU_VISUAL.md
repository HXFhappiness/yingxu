## 2. 游戏子菜单无法游玩的根因（已定位，请修复）

`design_top_wrapper.v` 只例化了两个游戏模块：
- `yingxu_invaders`（硬件，`sel_hw = I_game_mode & (I_game_sel==2'd1)`）
- `yx8_cart_soc_v2`（卡带，`sel_cart = I_game_mode & (I_game_sel==2'd2)`）

**`I_game_sel == 2'd0` 没有任何模块** → 打砖块选中后（`menu_pattern=8'h7F` → game_sel=0）屏幕全黑、无法游玩。

请从下列方案中选一个并说明理由：
- (a) 若卡带两个镜像（LBA 1_000_000 / 1_001_000）之一就是打砖块，把子菜单改成走卡带路径
      （`menu_pattern` 用 SW5 ON + SW6 选择镜像），并明确哪个镜像是哪个游戏；
- (b) 若 `yingxu_breakout.v` 可用（`src/user_source/hdl_source/yingxu_breakout.v`），
      在 wrapper 里为 `I_game_sel==2'd0` 例化它，输出接到 sprite 表（与 invaders 同接口风格）。

无论选哪个，验收要求：子菜单选"打砖块"能真正进入并操作；选"飞机大战"进入硬件 invaders（当前 `MENU_PAT_PLANE=8'h5F` 路径已工作）。

## 3. 背景渐变效果（用户要求）

当前 `yingxu_menu_ui` 的背景是纯色 `24'h0A1030`。用户希望接近原设计图的对角渐变（深蓝→浅灰）。

建议实现（低资源）：
- 用 `(pixel_x + pixel_y)` 构造 0..1998 的对角坐标，取高位做 8 段或 16 段查表
- 每段一个固定 RGB 常量（避免乘法器），在 case 里选择
- 或用几段线性插值（每段内用 `>>n` 移位近似）

参考原图色带（从左上深蓝到右下浅灰）：
```
24'h0A1030 (最深) -> 0B1838 -> 0F2040 -> 14284C -> 1A3055 -> 31415E -> 4A5570 -> 6B7280 -> 8A9099 -> B0B4B8 (最浅)
```
请按 `(x+y)` 均匀分布这 10 个色带，覆盖整个画面；不做条纹也行，纯对角渐变就够。
