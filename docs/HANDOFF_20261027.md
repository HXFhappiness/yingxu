## 1. 项目是什么

**映序（YingXu）** —— 一块 Anlogic FPGA 板子上做的"一台小机器"，用一条 HDMI 输出同时承载两件事：

1. **照片浏览器 + 精灵引擎**：SD 卡里的照片按 720p 播放；16 槽精灵引擎叠在画面上（可做 UI、游戏画面）
2. **自己的 8 位 CPU（YX-8）**：自研指令集 + 汇编器 + 模拟器，从 SD 卡"卡带"加载软件游戏，和硬件游戏共用同一套显示屏

**叙事**：硬件游戏和软件游戏跑在同一块板子上，全部逻辑在 FPGA 内，全国产 EDA 工具链。

**时间线**
- 初赛：**11.4**
- 冻结：**11.2**
- 今天：**10.27 深夜**（距初赛 7 天）

**已完成的对外材料**：`docs/REPORT_MATERIALS.md`（答辩素材）、`docs/PROJECT_INTRO.md`（项目简介）、`YX_美术资源包_v1.4.zip`（美术交付包）

## 3. 系统架构

```
SD 卡 (SPI)
   │  扇区数据
   ▼
[yx8_cart_soc]  ← 卡带 SoC（pix_clk 域）
   ├─ 加载器 FSM：解析 .yxc 头 → 逐词写入程序 RAM → zero-fill 剩余空间
   ├─ 程序 RAM：ram_dual_port_simple 1024×24，读延迟 2 拍（地址打一拍 + 输出寄存）
   ├─ YX-8 CPU：8 位机，24 位定长指令，1024 词程序空间，224 字节数据 RAM(dram)
   ├─ 精灵暂存/提交：8 个暂存寄存器 + SCOMMIT 写表
   └─ I/O：按键、随机数、PSG、分数、砖块位图
   │
   ▼  （精灵表写入）
[yingxu_sprite_engine] 16 槽，纯色矩形，行缓冲 ovl[0:4095]
   │
   ▼
[yingxu_tile_layer] 40×24 格 × 32px，程序化图案（星点/方块/渐变），可滚动
   │
   ▼
[design_top_wrapper] 源选择：照片模式 / 硬件游戏 / 卡带
   │
   ▼
HDMI 输出（1280×720@59.3）

同时：硬件游戏 yingxu_invaders / yingxu_breakout（纯 FPGA 逻辑，不经过 CPU）
串口遥测 yx8_uart_telem → COM4 115200（4 行/0.2s）
```

### 时钟域
- `sys_clk`：SD/SPI、加载器上游
- `S_pixel_clk`（pix_clk）：像素域，CPU、精灵、图块全部在这里
- 跨域：SD 字节 FIFO（sys → pix，1024 深异步 FIFO，**指针必须用 `[9:0]` 切片索引**）

### 5.2 卡带游戏在板上的实际表现

- **invaders（卡带）**：能跑，但**精灵位置全错**——炮台在左下角、外星人贴顶
- 原因链：绘制代码大量使用 `SHLI/SHRI` 算坐标 → 怀疑移位指令在板上不生效

### 5.3 关键结论（今天最重要的三个）

1. **取指延迟错位**是"卡带完全跑不起来"的根因：TD 把程序 BRAM 推断成**两拍读**，CPU 按一拍设计 → 每条指令晚一格。
   修复：地址先打一拍 `raddr_q` + CPU 增加 `S_WAIT`（`WAIT_CYCLES=1`），把延迟显式定死成两拍。
2. **精灵表上电是垃圾**：综合有 `eram_init off`，BRAM 上电内容未定义，而清表只在"模式切换"时触发 → 上电时 15 个槽是随机矩形（满屏彩虹条纹）。修复：上电强制扫一遍清表（`boot_wipe`）。
3. **程序区外是垃圾指令**：只写了程序段，其余未定义，CPU 跑出去就执行乱码。修复：加载完 `L_FILL` 把剩余空间清零。

## 7. 关键约定（务必记住）

### 7.1 拨码开关（板上实测：**OFF = 1**）

| 模式 | 开关 | 遥测 SW |
|---|---|---|
| 照片模式 | SW7 OFF（全部 OFF） | `FF` |
| **卡带模式** | **SW7 ON + SW5 ON** | `5F` |
| 硬件游戏 | SW7 ON + SW5 OFF | `6F`（含 SW4） |
| **内部自检（ROM）** | 以上 + **SW0 ON** | `5E` |

- `test_mode = ~sw[0]`：SW0 ON 时 CPU 从**组合 ROM** 取指（不碰 RAM），用于隔离故障
- `I_game_sel`：SW5 ON→卡带；SW5 OFF + SW6 ON→硬件流浪者

### 7.2 卡带 LBA 映射（容易搞反）

```
CART_LBA_A = 1,000,000   ← SW6 ON
CART_LBA_B = 1,001,000   ← SW6 OFF
```
拨动 SW6 会触发自动重载（不用断电）。

### 7.3 YX-8 ISA 速查

| 类别 | 操作码 |
|---|---|
| LDR | `0x30` 直接 / `0x31` 变址（X=R3） |
| STR | `0x32` 直接 / `0x33` 变址 |
| ALU 寄存器 | `0x10`–`0x1F`（ADD/ADC/SUB/SBC/AND/OR/XOR/CMP/SHL/SHR/ROL/ROR/MOV/INC/DEC/NEG） |
| ALU 立即数 | `0x20`–`0x2C`（同序 + `0x2C`=MOVI） |
| 分支 | `0x40`–`0x46`（BEQ/BNE/BCS/BCC/BMI/BPL/BRA），相对偏移 |
| JMP/JSR | `0x50`/`0x51`，**双字**：目标低字节在 A、高字节在第二字节 |
| 其它 | `0x01` CLC / `0x02` SEC / `0x03` WFI / `0x04` RTS / `0x05` HLT |

**重要约束**
- 寄存器 **8 位**，移位/加法会溢出截断（例如 `77<<3` 得 104）
- `LDR` **不设标志** → 分支前必须 `CMPI`
- 立即数**无符号**
- `yxa` 会把符号**统一大写** → `score` 与 `SCORE` 会冲突

### 7.4 卡带格式 `.yxc`

```
0x00 'YXCA'      4B
0x04 版本        1B
0x05 flags       1B
0x06 entry       2B (16)
0x08 words       2B (≤768)
0x0A dlen        2B
0x0C daddr       1B
0x10 title      16B
0x20 code       3B/word
```

### 7.5 精灵寄存器

| 地址 | 名称 |
|---|---|
| `0xE0`–`0xE7` | 砖块位图 8 字节（10×6 格，bit = row*10+col） |
| `0xE8` | SEN（使能） |
| `0xE9`/`0xEA` | X 低/高（11 位） |
| `0xEB`/`0xEC` | Y 低/高（10 位） |
| `0xED` | W（**7 位**，≤127） |
| `0xEE` | H（**6 位**，≤63） |
| `0xEF`/`0xF0` | 颜色低/高（RGB565） |
| `0xF1` | SCOMMIT（写槽号 0–15 触发提交） |
| `0xF2` | KEYS |
| `0xF4` | RAND |
| `0xF5` | PSG |
| `0xFE` | SCORE（同时驱动 LED 低 4 位） |

### 7.6 串口遥测（COM4 115200 8N1，4 行/0.2s）

```
A SEEN=1 BUSY=0 ERR=0 DNE=0 POR=1 FLU=0 KIL=0 RET=0 WFT=0 GM=1 CA=1
D MISE=0000 SCE=0001 SW=5F LS=4 WC=1B3 BU=0 SP=0000 F=F PC=213 DW=0000 I0=511200 RC=FBD3 I1=511200
```

- `SW` 原始开关字节（OFF=1）
- `LS` 加载状态（4 = 完成）
- `WC` 已加载词数
- `SP` 精灵提交计数、`DW` 数据写计数
- `F` = `{cpu_on, up_done, loaded_s, en}`
- `PC` CPU 当前 PC、`I0/I1` 首条/当前指令
- `GM`/`CA` 游戏模式/卡带激活

### 7.7 LED（**低有效**：值位=1 才亮）

```
led[3:0] = cart_active ? ~cart_score[3:0] : {...}
```

## 8. 调试方法论（这套很关键，别丢）

1. **先仿真，再上板**。`BADC0UNT=0` + `spr_commits` 是硬指标
2. **隔离用 `test_mode`（SW0 ON）**：CPU 从组合 ROM 取指，完全不碰 RAM/卡带。若 ROM 能跑、卡带不能 → 问题在存储/加载
3. **判官程序用汇编器生成**，不要手写 ROM 表（今天就是手写把自己坑了）
   - 写 `.asm` → `yxa.py` 汇编 → `yxem.py` 先验 → `write_cart.py` 写卡
4. **结果用"大色块颜色"表达**（绿=对 红=错），不用数格子、不用看 LED

## 9. 踩过的坑（血泪清单）

| 坑 | 症状 | 对策 |
|---|---|---|
| **PowerShell `-replace` 大小写不敏感** | `score`→`SCORE`、`[SCORE]`→`[pts]`、注释吞掉 `reg` 声明 | **一律用 Python 脚本改文件**，显式 `encoding` |
| **PowerShell 命令行里的引号/`<`/`$`** | 脚本被 PowerShell 解析成命令，反复报错 | 补丁写成 `.py` 文件再执行，不要内联 `-c` |
| **GBK 编码文件** | 用 UTF-8 读写 `design_top_wrapper.v` 会乱码、合并行 | `open(..., encoding='gbk', errors='replace')`，改完 `encode('gbk')` |
| **字节 FIFO 指针越界** | 11 位指针直接索引 1024 深数组 → 读 X | 索引用 `[9:0]` 切片 |
| **跨时钟域写 RAM** | TD 丢写，`I0=000000` | 所有 RAM 写搬进 pix_clk |
| **`eram_init off`** | BRAM 上电内容未定义 | 上电必须显式初始化（清表、清零） |
| **BRAM 两拍读** | 指令错位一格 | 地址打一拍 + CPU 等一拍 |
| **COM4 掉线** | `A device attached to the system is not functioning` | 拔插 USB |
| **Tcl 第一行被吃** | 脚本少执行一条命令 | 开头加垃圾行 |
| **SD 卡在板里** | `E:` 盘不存在，写卡失败 | 物理把卡插回读卡器 |
