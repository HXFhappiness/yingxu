# 映序 · 硬件分层与软件栈（2026-10-29）

> 回答两个问题：**硬件现在有几层？有没有 CPU 和编译器？**

---

## 一、硬件分层（6 层）

```
┌─────────────────────────────────────────────────────────────┐
│ L5 音频    PSG(4 事件音) + [待做: WAV 播放器] → 混音         │
│            → audio_arc_calculate → HDMI 音频包               │
├─────────────────────────────────────────────────────────────┤
│ L4 处理器  yx8_cart_soc：YX-8 CPU + 程序 RAM + 数据 RAM      │
│            + 加载器 FSM（SD → FIFO → RAM → 清零填充）        │
├─────────────────────────────────────────────────────────────┤
│ L3 应用    ① 照片浏览器  ② 硬件游戏(FSM)  ③ 卡带 SoC        │
│            （三选一，由 app/sel 信号切换）                    │
├─────────────────────────────────────────────────────────────┤
│ L2 像素合成  图块层 40×24×32px（程序化图案）                 │
│             精灵引擎 16 槽 + 砖块层 10×6 + 行缓冲 4096×16     │
│             + 内置 48×48 位图精灵通路                        │
│             照片源：SD → SDRAM 4 端口 → 视频播放器           │
├─────────────────────────────────────────────────────────────┤
│ L1 系统/包装  design_top_wrapper：模式选择、HDMI 打包(TMDS)  │
│             按键消抖、精灵表擦除、音频 ACR                   │
├─────────────────────────────────────────────────────────────┤
│ L0 引脚/时钟  顶层 hardware_test_*.v：PLL、50MHz、IO.adc     │
│             串口遥测 115200（4 行/0.2s）                     │
└─────────────────────────────────────────────────────────────┘
```

### 各层的规模与关键参数

| 层 | 关键模块 | 参数 |
|---|---|---|
| L0 | `hardware_test_P0_UART_V5_CRC32.v` | 系统时钟 50MHz、像素时钟 ≈73.3MHz、HDMI 1280×720@59.3 |
| L1 | `design_top_wrapper.v` | 模式/游戏选择、TMDS 4 lane、音频 ACR（N=6144）|
| L2 | `yingxu_tile_layer` / `yingxu_sprite_engine` | 图块 40×24 格×32px；精灵 16 槽（宽 ≤127、高 ≤63）+ 砖块 60 格 |
| L3 | `yingxu_bmp_loader` / `yingxu_invaders` / `yx8_cart_soc` | 照片 6 张轮播；硬件游戏 12 架 FSM；卡带 SoC |
| L4 | `yx8_cpu.v` + `yx8_cart_soc.v` | 见下表 |
| L5 | `yingxu_psg` + `audio_arc_calculate` | 48kHz 采样、24bit 立体声、方波 |

## 二、CPU 规格（YX-8）

| 项 | 参数 |
|---|---|
| 位宽 | **8 位**数据 / **24 位定长指令** |
| 通用寄存器 | 8 个（R0–R7），**R3 兼作变址寄存器 X** |
| 程序空间 | **1024 词**（24bit×1024 = 3KB），指令/数据统一寻址 |
| 数据 RAM | **224 字节**（0x00–0xDF），0xE0 以上是 I/O |
| 指令周期 | 约 **2 拍**（含取指等待），73.3MHz 下理论 ≈36 MIPS；游戏里由 `WFI` 帧同步限制到 60Hz 主循环 |
| 支持指令 | 传送/算术逻辑/移位/比较/相对分支/绝对跳转/子程序/复位·停机·等待 |
| 取指对齐 | 程序 RAM 是**两拍读**，CPU 用 `S_WAIT` 状态严格对齐（这是 10-27 的关键修复）|
| 无 | 乘法、除法、浮点、中断、MMU、Cache |

### I/O 映射（0xE0 以上）
| 地址 | 功能 |
|---|---|
| 0xE0–0xE7 | 砖块位图 8 字节（10×6 格）|
| 0xE8–0xF1 | 精灵暂存：EN / X / Y / W / H / 颜色 / **SCOMMIT(提交槽)** |
| 0xF2 | 按键 |
| 0xF4 | 随机数 |
| 0xF5 | PSG |
| 0xFE | 分数（同时驱动 LED 低 4 位）|

## 三、软件栈（PC 侧工具链）

| 环节 | 工具 | 说明 |
|---|---|---|
| 编写 | 任意文本编辑器 | 汇编语言 `.asm` |
| **汇编** | **`tools/yxa.py`** | `.asm` → `.yxc` 卡带；**注意：没有 C 编译器，只有汇编器** |
| 模拟 | `tools/yxem.py` | 指令级机器：可跑帧、打印寄存器/RAM/精灵表 |
| 符号检查 | `tools/check_syms.py` | 检测大小写归一后的符号撞名（踩过坑）|
| 写卡 | `tools/write_cart.py` | 按固定 LBA 写 SD（自带 2048 扇区偏移补偿）|
| 音乐 | `tools/music2sd.py` | MP3/FLAC → 48k PCM → 写固定槽 |
| 美术 | `tools/yxpad.html`（v1.5）| 网页像素画板：1px 网格/对称/选区移动/细化×2/取色 |
| 调试 | `tools/grab.py` + `screen_probe.py` + `track.py` | 采集卡抓帧 → 色块坐标/颜色/逐帧轨迹 |
| 调色/图块 | `tools/palette.py`、`tilekit.py` | YX-256 调色板、图块表与关卡校验 |

### 编译/运行全流程
```
foo.asm --yxa--> foo.yxc --write_cart--> SD 卡固定 LBA
                    ↘ --yxem--> 先仿真验证（寄存器/精灵/内存）
                                   ↓
                        板上断电重上电 → 卡带 SoC 加载 → YX-8 执行
```

## 四、明确"没有"的东西（答辩要能答）

| 没有 | 说明 |
|---|---|
| **C 编译器** | 只有汇编器。游戏用汇编写（打砖块 492 词、流浪者 606 词）|
| **操作系统** | 无进程/调度/内存管理；卡带就是一段程序，`WFI` 等帧同步 |
| **文件系统** | SD 卡是**裸扇区读写**，没有 FAT 驱动；卡带与音乐都放固定 LBA |
| **中断** | 无中断控制器，靠 `WFI` + 帧同步轮询 |
| **乘法器/浮点** | 只有加减移位；坐标换算用移位和查表 |

这几条不是缺陷，是**取舍**：把 LUT 花在显示管线和精灵引擎上，
处理器保持极小（约占 1000 LUT），才能在一块 19,600 LUT 的芯片里同时装下
图块层、精灵引擎、SDRAM 帧缓冲、SD 加载器和 CPU。

## 五、一句话概括结构

> **一块 FPGA 里同时有两台机器**：
> 一台是**纯硬件状态机**（图块层 + 精灵引擎 + 游戏 FSM，零处理器参与）；
> 一台是**完整的小计算机**（8086 式的 8 位 CPU + 3KB 程序 + 224B 内存 + I/O 端口 + SD 卡带加载器）。
> 两者共享同一条 1280×720 的像素管线和同一份音频样本。
