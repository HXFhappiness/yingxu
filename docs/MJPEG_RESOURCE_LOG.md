这里只记录本地TD报告，不用Python模型或估算充当实测。冻结基线10519 LUT / 39 BRAM / 0 DSP来自交接文档，非本次重新测量。默认目标为新增7600 / 19 / 13，总BRAM 58；S1完成后的同配置工程另立累计增量基准。

|---|---|---|---|---|

每阶段必须先把该模块以实际连接加入TD工程综合一次，记录LUT/REG/BRAM/DSP、时钟slack、源提交、日志路径、TD版本/选项；源SHA要与注册工程相符。保留每阶段总量差及模块层级利用率，不能把旧模块优化抵消冒充新增模块没有成本。

对每类资源计算 `abs(累计实测增量 - 累计估算) / 累计估算`。任一超过30%即停止、重设计；估算0而新增非0同样停机。30%以内仍须满足芯片总预算、19块BRAM目标与pix无新负裕量；计划外第20块必须复审。没有日志或本地尚未执行时不准填0/通过。表中“未测”是缺少证据，不是通过。

## D11 面积裁减（2026-11-02）

用户报告 D10 `4a26c65`：syn 18250 LUT，phy 18537/19600。D11 已移除硬件
invaders/breakout，保留两个 YX-8 卡带入口；UART 原生代理 1360→355 LUT 单元，
0→1 BRAM，并退役顶层 G6 音乐诊断覆盖 mux。额外 BRAM 用于同步格式 ROM，初始化
在 RTL 内。用旧 TD UART 比例校准的总量规划值为 16472（84.04%），不含 G6 额外收益。
**新 TD 的 LUT/REG/BRAM/DSP、时序和 <85% 门禁均未实测**，不能将此规划值填入实测栏。
U_tile 暂保留；验证与原始代理日志见 [D11 报告](D11_AREA_REDUCTION.md)。
