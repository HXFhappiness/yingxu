# D7 任务书：主菜单改为纯硬件绘制

> 2026-11-02。板测定案：菜单靠 BMP 加载显示时画面以约 3 px/秒向左漂移。
> 根因：`yingxu_bmp_display` 的 player 逐字喂像素，SDRAM 读口被显示刷新抢占时 FIFO 欠载 →
> 像素流停顿 → 帧边界相对 vsync 滑移 → 每帧偏移一点，视觉上就是慢速滚动。
> 另外每换一次画面要重载 2.76 MB（约 2.5 秒），且每张背景占卡空间。

改为纯硬件绘制后的收益：**零漂移、零加载延迟、零卡空间、开机不依赖 SD 卡**。

## 1. 已提供资产（本分支）

`src/user_source/hdl_source/yingxu_cn_font.v` — 32×32 1bpp 中文字模，17 字，已渲染回图逐字视觉校验：

```
module yingxu_cn_font(
    input  wire [4:0]  char_idx,
    input  wire [4:0]  row,
    output reg  [31:0] bits);
```

- 1 = 笔画；bit31 = 最左像素；行序自上而下
- 字符索引：`0图 1片 2游 3戏 4视 5频 6音 7乐 8关 9于 10打 11砖 12块 13飞 14机 15大 16战`
- 请把该文件加入 `.al` 工程文件列表（`prepare_unified_td.py` 里同步）

## 2. 新增模块 `yingxu_menu_ui.v`

像素域工作（输入 `S_pixel_clk` / `S_pixel_x` / `S_pixel_y` / `S_pixel_active`），
输出 `[23:0] menu_rgb`，作为 sprite engine 的 `bg_rgb` 输入（文字和绿标由后续图层叠加）。

端口建议：

```
input  wire        clk, rst;
input  wire [10:0] pixel_x, pixel_y;
input  wire        pixel_active;
input  wire        menu_visible;   // 菜单显示中
input  wire [0:0]  page;           // 0 = 主菜单, 1 = 游戏子菜单
input  wire [2:0]  sel;            // 当前选中项
output wire [23:0] menu_rgb;
```

## 4. 页面内容

- **page 0（主菜单，5 项）**：图片 / 游戏 / 视频 / 音乐 / 关于
- **page 1（游戏子菜单，2 项）**：打砖块 / 飞机大战
- **切页只换文字与绿标行，背景与面板完全不变**（用户明确要求，也是省资源的关键）

## 5. 按键语义（配合 D6）

- key1：`sel` 下移循环（page 0 循环 5 项，page 1 循环 2 项）
- key0：
  - page 0, sel=0（图片）→ 进入照片浏览
  - page 0, sel=1（游戏）→ 切到 page 1
  - page 0, sel=2/3/4 → 进入视频 / 音乐 / （关于 v2 占位）
  - page 1, sel=0（打砖块）→ `menu_pattern = 8'h7F`（SW5/SW6 OFF → game_sel=0 → 硬件打砖块）
  - page 1, sel=1（飞机大战）→ `menu_pattern = 8'h5F`（SW5 OFF/SW6 ON → game_sel=1 → 硬件飞机大战）
- **物理 SW7 ON + key0 短按** = 从任何模式/子菜单退回主菜单（见 D6 commit c25b9c5，**请合并该 commit**，
  当前统一分支仍是"长按 key0 2s"，会与模式内 key0 操作冲突，用户已明确要换成 SW7+key0）

## 6. 字模读取时序

`pixel_x/pixel_y` 是当拍扫描坐标，字模 ROM 是组合读（case）。请确保同一拍内完成
`char_idx → row → bit` 选择，或加一级流水并相应延后 `menu_rgb` 对齐，
避免文字相对精灵整体偏移 1 像素（与 `bg_rgb` 输入对齐）。

## 7. 验收判据（仿真）

1. page 0 显示 5 项，每行文字包围盒的 y 范围与上表一致（像素级断言）
2. page 1 只显示 2 项，背景与面板与 page 0 **逐像素相同**
3. `sel` 改变时只有绿标位置变化，文字与背景逐像素不变
4. 字模抽查：图 / 游 / 打 等字在若干 (x,y) 处的亮灭与 ROM 位一致
5. 与精灵引擎合成后，文字不被绿标遮挡（绿标 x 930..942，文字 x ≥ 950）
6. 菜单可见时不再触发 BMP 加载（`img_restart` / `load_start` 不该因菜单出现而产生）

## 8. 顺带记录（非本任务）

照片模式仍走 BMP 回放路径，同样有 3 px/秒漂移。若有低风险帧锁定办法
（例如 `media_frame_start` 时强制重置读指针，或加大 `rd2` 预取深度），可另开小任务；
否则先记录，菜单先走 D7 路线。
