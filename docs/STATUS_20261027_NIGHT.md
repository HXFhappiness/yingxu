## 今天修的四个真 bug

1. **取指延迟错位**（根因）：TD 把程序 BRAM 推断成两拍读，CPU 按一拍设计 →
   每条指令晚一格。修法：地址打一拍 `raddr_q` + CPU `S_WAIT` 状态，显式定成两拍。
2. **精灵表上电是垃圾**：`eram_init off`，BRAM 上电内容未定义，而清表只在模式切换时触发
   → 上电时 15 个槽是随机矩形（满屏彩虹条纹）。修法：上电强制扫一遍清表 `boot_wipe`。
3. **程序区外是垃圾指令**：加载完只写了程序段，其余 BRAM 未定义。
   修法：`L_FILL` 状态把剩余空间清零（跑出程序只会执行 NOP）。
4. **移位器改成显式 case**：`{8'b0,v1} << sh` 这种动态移位在 TD 里行为不可靠，
   改成纯拼接 + case（单元测试通过：4<<5=128、77<<2=52）。
