# G6 修复：WAV 播放器两处数据损坏（2026-10-30 凌晨）

> 症状：SW4 开启后"小杂音，然后刺耳的噪音"（g25 实测）。
> 诊断音已静音，说明 PSG→HDMI 链路通，坏的是 WAV 数据本身。
> 修复后固件：**g26**（`out/build_g26.txt` + `build_g26b.txt`，05:33 bit）。
> 回退位：`out/bitstream_backup/g25_pre_g6fix.bit`。

## 根因一：16bit→24bit 扩位是 30 位拼接塞 24 位（位序旋转）

```verilog
// 旧（1+16+13 = 30 位，高位截断后 = {L[10:0], L[15:3]}，符号位变成 L[10]！）
wav_l <= {rdata[31], rdata[31:16], rdata[31:19]};
// 新（1+16+7 恰好 24 位；×128 = -6dB；16bit 满幅 ×128 = 2^22 < 2^23 不溢出）
wav_l <= {rdata[31], rdata[31:16], 7'd0};
```

每个样本位序旋转 → 输出是"跟着歌曲包络起伏的刺耳噪音" ✓ 与症状吻合。

## 根因二：清零分支挂在 out_tick，与 pop 差一拍 → 每拍 1 拍宽清零毛刺

`rate_tick` 是 `out_tick` 打一拍的寄存器。旧代码 `else if (out_tick) wav_l <= 0`
在 rate_tick 尚未升起的那个拍清零；若消费端在该相位锁存，音乐全没/全是噪声。
修复：清零分支改挂 `rate_tick`（与 pop 同一拍，互斥且完备）。
