## 1. 硬件版流浪者"子弹没碰到就消失" —— 仿真定位到根因

### 症状
子弹从敌机旁边飞过（或离得很远）就触发命中，被击落的却不是看得见的那架；
后来又出现"敌机已消失、却仍从虚空射出子弹"。

### 定位方法（这次靠仿真，不靠猜）
新写了 `sim_ce/tb_inv.v`：实例化 `yingxu_invaders`，逐帧记录子弹与 6 架敌机的
屏幕矩形，凡出现"没有矩形重叠却触发了 `o_ev_hit`"就打印。

```
FALSE HIT f=330 bullet(616,156)
            enemy 0 (144,120)  enemy 1 (272,120)
            enemy 2 (0,184)    enemy 3 (60,184)
```

### 根因
```verilog
// 错：COLS=4 但每排实际只有 2 架
wire in_range = (d >= 0) && (d < COLS*SPACE_X) && (d[6:0] < ENEMY_W[6:0]);
// 对：有效占位是 2 格
wire in_range = (d >= 0) && (d < 2*SPACE_X) && (d[6:0] < ENEMY_W[6:0]);
```
`d` 是子弹相对队首的偏移。原来允许到 512px（4 格），但每排只有 2 架（0..255），
于是子弹落在"第 3、4 格"这个**没有飞机的虚拟区**时也会命中。
修好后仿真 1200 帧 **0 次误判**。

### 连带修掉的
- **命中索引**：`emask` 实际是"每排 2 架"的 6 位布局，索引必须是 `{band, d[7]}`（3 位）。
  中途我错误地改成 4 位 `{band, d[8:7]}`，导致"打黄机消紫机、紫机打不掉"。
- **虚空子弹**：敌机半出界（`e_vis` 允许 96px 出界）时仍会开火 →
  `spawn*_ok` 改为要求整机在屏内（左右各留 48px）。
- **清空后立刻重生**：改为 `emask=0` 空 120 帧（2 秒）再入场（顺带空场期间关掉 6 个精灵槽，降载）。

### 教训
**仿真测试台 > 盲改**。两个 bug（range 上限、索引位宽）都是"看起来等价"的写法，
只有把子弹/敌机矩形打印出来才现形。以后再遇到"判定类"问题，先写 TB。

## 2. 全面放大比例（视觉一致性）

之前我方 32×32、敌机 96×48，比例失衡。现在统一：

| 元素 | 硬件版 | 卡带版 |
|---|---|---|
| 我方 | **48×48**（飞船位图）| **48×48**（飞船位图），y=664 |
| 我方子弹 | 6×18 | **12×24** |
| 敌机 | 96×48（8 架设计）| **64×40**，间距 10 q8 |
| 敌弹/炸弹 | 6×18 | **12×24** |

### 飞船位图升级到 48×48
- 掩码从 32×32（64bit/行）升级到 **48×48（96bit/行）**，1.5× 最近邻从原 BMP 采样
- 引擎触发条件同步改成"槽宽高都等于 48"
- 代价：LUT +约 100（9153 → 约 9250）
